# LEVEL UP — V1

A mobile-first real-life RPG dashboard designed to work on iPhone and deploy through GitHub Pages.

## V1 includes
- Player level and XP
- Daily missions
- XP rewards
- Skill points
- Streak counter
- Player progression cards
- Level-up popup
- Local browser saving with localStorage
- Responsive mobile layout

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and open the generated Pages URL on your iPhone.

## Important
This is intentionally plain HTML/CSS/JavaScript for V1. It keeps the foundation simple before adding accounts, cloud data, AI food scanning, workouts, soccer training, nutrition calculations, and the skill tree.
